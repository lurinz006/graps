# 📚 GRAPS Setup & Execution Index

Welcome to the  G-CRAPS platform. To get the project up and running on your machine, please follow the documentation in this order:

---

## 🛠️ Step 1: Install System Prerequisites
Ensure that PHP, Composer, Node.js, Python, PostgreSQL, and the PostGIS spatial extension are installed on your host operating system.
👉 [INSTALL_PREREQUISITES.md](INSTALL_PREREQUISITES.md)

---

## 🚀 Step 2: Initialize & Configure the Workspace
Set up configuration secrets (`.env`), install composer and npm modules, configure the Python virtual environment, and run initial database seeding.
👉 [CLONE_AND_SETUP.md](CLONE_AND_SETUP.md)

---

## 🖥️ Step 3: Run the Services & Test Suites
Commands to launch your local API server, background queue worker, Vite frontend compiler, and run backend/frontend test suites.
👉[how_to_run.md](how_to_run.md)
